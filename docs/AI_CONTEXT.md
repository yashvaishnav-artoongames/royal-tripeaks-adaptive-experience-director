# AI Context — TriPeaks AED

## Project
TriPeaks Solitaire Adaptive Experience Director (AED) demo.

## Current Baseline
Single-page browser demo with Plus Card obstacle visualization.

## Stable Principles
- Repository is the durable source of truth.
- Plus Card is a specific map obstacle.
- Verified, live, inferred, and proposed behavior must be distinguished.
- AED decisions should be explainable through trigger, inputs, decision, action, state, player experience, telemetry, downstream plan, and fallback.

## Current Direction
Move to a hosted, Git-versioned project with persistent Claude project/repository memory so new chats can continue without previous conversation history.
