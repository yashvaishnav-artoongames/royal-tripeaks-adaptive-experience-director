# Decisions

## D-001 — Repository as Durable Project Memory
Status: APPROVED
Decision: Store durable AI/project context in version-controlled project files.
Reason: New Claude chats must be able to continue without old conversation history.

## D-002 — One Existing Demo Project
Status: APPROVED
Decision: Modify the existing demo instead of generating duplicate HTML files.
Reason: Enables hosting, versioning, review, and rollback.

## D-003 — Plus Card Is a Map Obstacle
Status: APPROVED
Decision: Model Plus Card as a specific map obstacle, not a generic property of every card.
Reason: Its lifecycle can affect deck planning and AED behavior.
